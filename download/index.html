How to install

  1. Tap Download APK. If Chrome warns about the file type, choose Download anyway.
  2. Open the downloaded PricePulse.apk from your notifications or the Downloads folder.
  3. If Android asks, allow Install unknown apps for your browser or Files app, then go back and tap Install.
  4. Open PricePulse from your home screen.

Good to know

Why does Android show a warning?

Apps installed outside the Play Store always get an “unknown source” prompt. PricePulse is a web app packaged as an Android app, and it only needs an internet connection to load.

Does it update by itself?

Yes. The app checks for a newer version each time you open it and offers a one-tap update, so you only need a new APK if the app icon or name changes.

I’d rather not install an APK

Open the web version in Chrome, tap the menu (⋮) and choose Install app. It works the same way.

Is it safe?

The APK is signed with the developer’s own key. You should only install APK files from sources you trust, and this page is the only official place for it.
